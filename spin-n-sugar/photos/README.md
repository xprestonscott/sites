# Spin N Sugar — photo slots

Save the real photos into this folder with these exact filenames. Each one
takes over its spot automatically. Anything missing falls back to hand-built
candy artwork, so the page never looks broken while you're still collecting
pictures.

JPG for photos, PNG for the logo. Roughly 1600px on the long edge is plenty.

| Filename | What goes here |
| --- | --- |
| `logo.png` | The Spin N Sugar logo. Transparent PNG looks best — it sits in the round badge in the header and footer. |
| `hero.jpg` | The booth set up and ready (the Facebook cover shot works well). |
| `spinning.jpg` | Live spinning in action — this one anchors the "Who we are" section. |
| `dome-cups.jpg` | **The stacked dome cups on the counter.** Also used as the Dome Cup product shot. |
| `fall-sugars.jpg` | **The Fall Sugars chalkboard flyer.** |
| `cake-12.jpg` | A 12 inch cotton candy cake. |
| `cake-custom.jpg` | A colour-matched cake. |
| `tub.jpg` | A tub (or a stack of them). |
| `packaged.jpg` | Sealed packaged cotton candy, ready to ship. |
| `cone.jpg` | A hand-spun cone. |
| `g1.jpg` | Gallery — spinning live. |
| `g2.jpg` | Gallery — party colours. |
| `g3.jpg` | Gallery — packed and ready for pickup (wide tile). |
| `g4.jpg` | Gallery — out at an event. |

The product shots are matched by product `id`, so if you add a new item to the
`PRODUCTS` list in `index.html` with `id: 'sampler'`, its photo goes here as
`sampler.jpg`.
